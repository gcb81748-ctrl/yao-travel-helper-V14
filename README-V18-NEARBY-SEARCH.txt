V18 附近搜尋強化版

新增功能：
- 附近景點升級成分類搜尋卡片
- 附近餐廳升級成分類搜尋卡片
- 附近神社升級成分類搜尋卡片
- 使用手機目前位置開啟 Google Maps 搜尋
- 不需要 Google Maps API Key
- 不增加費用

注意：
- 第一次使用時，手機會詢問定位權限，請允許。
- 如果定位失敗，系統會自動改用一般 Google Maps 搜尋。
- iPhone 請用 Safari 開啟，定位權限比較穩定。

使用方式：
1. 解壓縮 ZIP
2. 覆蓋到 D:\yao-travel-helper
3. GitHub Desktop：
   Summary 輸入：V18 nearby search
   Commit to main
   Push origin
4. 等 GitHub Pages 部署完成
5. 用以下網址測試：
   https://gcb81748-ctrl.github.io/yao-travel-helper-V14/?v=18

如果手機主畫面 APP 還讀舊版：
1. 刪除 iPhone 主畫面舊 APP
2. Safari 開上面網址
3. 再重新加入主畫面
